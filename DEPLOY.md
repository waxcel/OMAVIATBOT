# Деплой бота на сервер Play2GO (Pterodactyl)

## Важно про тариф CODING-2

На тарифе **172 МБ RAM** — Chromium (браузер для парсинга изменений) туда **не влезет**.
Поэтому бот на сервере работает в **лёгком режиме** (~50–70 МБ): он не запускает браузер,
а берёт изменения из файла `changes_data.json`, который каждые 15 минут обновляет **GitHub Actions**.

Локально (на твоём ПК) бот по-прежнему может работать в обычном режиме — просто не задавай `CHANGES_JSON_URL`.

---

## Шаг 1. GitHub (сборщик изменений)

1. Создай **публичный** репозиторий на GitHub (например `omaviat-bot`).
2. Загрузи туда все файлы из `bot_deploy.zip` (распакуй и перетащи папкой, либо через git push).
   Важно: в репозитории должны лежать `.github/workflows/fetch-changes.yml`, `actions/fetch_changes.py` и весь код бота.
3. Открой вкладку **Actions** → выбери workflow **fetch-changes** → **Run workflow** (проверочный запуск).
4. Через пару минут в корне репо появится файл **`changes_data.json`** — это и есть данные изменений на неделю.
   Далее Actions будет обновлять его сам каждые 15 минут (и дополнительно в 19:52 и 19:58 — перед вечерней рассылкой).
5. Скопируй ссылку на сырой файл — она понадобится на шаге 2:
   `https://raw.githubusercontent.com/<ТВОЙ_НИК>/<РЕПО>/main/changes_data.json`

> Репозиторий публичный — это нормально: в нём нет токена бота и никаких секретов.
> Токен задаётся на сервере переменной окружения, в код он не пишется.

## Шаг 2. Переключить сервер на Python

Сервер заказан с ядром **node.js**, а бот — на Python.
В панели Play2GO: **Settings → Reinstall server** (если позволяет выбрать ядро — выбери **python**)
или напиши в **Support** тикет: «Переключите сервер с node.js на python egg, пожалуйста».
Проверить легко: после запуска в **Console** должна быть версия python (`python --version`).

## Шаг 3. Залить бота на сервер

1. Вкладка **Files** → кнопка **Upload** → загрузи `bot_deploy.zip`.
2. ПКМ по архиву → **Unarchive** (распакуется в корень сервера).
3. Вкладка **Startup**:
   - **BOT_TOKEN** (или через Variables/Environment): `8929073046:AAE...` — твой токен;
   - **CHANGES_JSON_URL**: ссылка из шага 1;
   - главный файл: `main.py` (если в Startup есть поле «app file / main file»).
4. Нажми **Start**.

Если egg не ставит зависимости сам — во вкладке **Console** выполни:
```
pip install -r requirements.txt
```
(Chromium на сервер НЕ ставим — `playwright install` не нужен.)

## Шаг 4. Проверка

В **Console** должны появиться строки:
```
INFO aiogram.dispatcher: Run polling for bot @godwaxybot ...
INFO notifier: Следующая проверка изменений: ... 20:00 ...
```
Дальше в Telegram: `/start` → кнопка «Расписание», стрелки листают дни.

## Стоп на локальном ПК

После запуска на сервере останови бота на компьютере (один токен = один poller,
два одновременно будут конфликтовать: Telegram начнёт отвечать ошибкой 409).

## Если что-то не так

- **409 Conflict в логах** — бот ещё запущен на ПК, останови его.
- **«Не удалось получить JSON изменений»** — проверь `CHANGES_JSON_URL` (путь `main`, а не `master`).
- **Bot template / egg без pip** — тикет в поддержку: «python egg с pip».
- **Не хватает памяти** даже в лёгком режиме — маловероятно; логи в `bot.log` покажут.
