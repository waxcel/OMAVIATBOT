# Деплой бота на сервер Play2GO (Pterodactyl)

## ВАЖНО: oat.ru блокирует зарубежные датацентры

С сайта oat.ru соединения с IP датацентра Play2GO **отбрасываются** (проверено:
DNS ок, но TCP-подключение молча зависает). Значит, серверу нужен один из вариантов ниже.
Сам бот на P2G работает нормально — Telegram и всё остальное доступны.

### Вариант A: GitHub-зеркало (бесплатно, recommended)

GitHub Actions (облако Microsoft) собирает ВСЁ — расписание, номера недель, изменения —
и складывает в JSON в репозитории. Сервер читает только этот JSON, oat.ru ему не нужен.

1. Создай **публичный** репозиторий GitHub, залей туда всё содержимое архива.
2. Вкладка **Actions** → workflow **fetch-changes** → **Run workflow**.
3. Смотри лог: строка `PROBE oat.ru: OK` — отлично, появится `changes_data.json`.
   Если `FAIL` — GitHub тоже заблокирован сайтом, переходи к варианту B.
4. На сервере в Startup задай:
   `CHANGES_JSON_URL = https://raw.githubusercontent.com/<ник>/<репо>/main/changes_data.json`
5. Start. Бот работает без браузера, отвечает мгновенно.

Actions будет обновлять данные каждые 15 минут (и в 19:52/19:58 перед вечерней рассылкой).

### Вариант B: российский прокси (~100–200₽/мес)

Купи HTTP(S)-прокси с российским IP и на сервере в Startup задай:
`CHANGES_PROXY = http://логин:пароль@ip:порт` (или `socks5://ip:порт`).

Все запросы к oat.ru пойдут через прокси — и расписание, и изменения
(браузер на сервере работает, библиотеки уже установлены). GitHub не нужен.

### Вариант C: сервер с российским IP

Перенести бота на дешёвый РФ VPS (Timeweb/Beget/VDSina, от ~150₽/мес) — там oat.ru доступен напрямую.
Инструкции те же: залить архив, `pip install -r requirements.txt`, первый старт скачает Chromium.

## Установка на сервер (общие шаги)

1. **Files** → **Upload** → загрузи `bot_deploy.zip` → ПКМ → **Unarchive**.
2. **Startup**:
   - `BOT_TOKEN` = токен бота;
   - `CHANGES_JSON_URL` и/или `CHANGES_PROXY` — по выбранному варианту выше
     (если оба пусты — бот попробует ходить на oat.ru напрямую и на зарубежном сервере это не заработает);
   - главный файл: `main.py`.
3. **Start**. При первом старте бот сам поставит Chromium и системные библиотеки (2–4 мин, разово).
   В варианте A браузер не нужен вовсе.
4. Проверка в логе:
   ```
   Проверка сети: oat.ru доступен / Зеркало загружено ...
   Run polling for bot @godwaxybot ...
   Следующая проверка изменений: ... 20:00 ...
   ```

## Возможные проблемы

- **409 Conflict** — бот запущен ещё где-то (например, на ПК). Останови там.
- **«oat.ru НЕДОСТУПЕН с этого сервера»** — ожидаемо на зарубежном датацентре; включи вариант A или B.
- **«Зеркало недоступно»** — проверь CHANGES_JSON_URL (ветка `main`, репо публичный) и что Actions зелёный.
- **403/через прокси не пускает** — проверь логин/пароль прокси; для chromium используется `--proxy-server`.
- **Медленный первый ответ** (~7–10 сек) — норма для режима с браузером; в режиме A ответы мгновенные.
